Peer-to-Peer Campus Network is a major project developed using Python to demonstrate the implementation of Data Structures and Algorithms (DSA). 
In this system, students are represented as nodes and their friendships are represented as edges in a graph structure. The project allows users to add student profiles, create friend connections, search students, find connection paths using BFS, and display a leaderboard based on GPA.
The project uses important DSA concepts such as Hash Tables for student storage, Graphs for managing connections, Binary Search Trees for searching students, and Sorting algorithms for ranking students. 
This project is designed to help understand how DSA concepts can be applied in real-world applications like social networking systems.
